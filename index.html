    🏠 우리 방 꾸미기 사용 방법

    가구를 골라 방에 놓고, 10cm 격자에 맞춰 옮겨 보세요. 겹치거나 문을 막으면 빨간색으로 알려 줘요.

    🖱️ 마우스 (컴퓨터)

    • 가구 클릭 후 끌기: 이동
    • 빈 곳 왼쪽 드래그: 화면 돌리기
    • 오른쪽 드래그: 화면 옮기기
    • 휠: 확대 / 축소

    👆 터치 (휴대폰·태블릿)

    • 가구 눌러서 끌기: 이동
    • 빈 곳 한 손가락: 화면 돌리기
    • 두 손가락: 확대 / 옮기기
    • 빈 곳 톡: 선택 해제

    ⌨️ 키보드 단축키

    • R 회전 · Delete 삭제
    • 방향키 10cm씩 이동
    • PgUp/PgDn 높낮이 ±10cm
    • Ctrl+Z 되돌리기 · Ctrl+D 복제

    💡 알아두기

    • 높낮이: 바닥에서 띄운 높이 (벽 선반, 책상 위 스탠드)
    • 높이 2cm 이하(러그 등)는 다른 가구와 겹쳐도 괜찮아요
    • 바닥의 갈색 부채꼴은 문이 열리는 공간이에요
    • 작업은 이 기기에 자동 저장돼요
